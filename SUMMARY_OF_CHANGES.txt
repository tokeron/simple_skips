SAMPLE DATASET STRUCTURE:
--------------------------
CSV Columns:
- subset: animals, celebrities, copyrights, places
- variant: specific, placeholder, extension_only
- item_index: Index of selected item (0-4)
- extension_index: Index of selected extension
- original_item: The base item (e.g., "a cow", "abraham lincoln")
- placeholder: Generic placeholder (e.g., "an animal", "a person")
- prompt_extension: The extension phrase
- prompt: Final prompt text to use for generation

Placeholders:
- animals → "an animal"
- celebrities → "a person"
- copyrights → "a character"
- places → "a place"

PARALLEL PROCESSING:
--------------------
To run multiple jobs in parallel, modify these variables in main.py:

Job 1 - Process prompts 0-19:
  start_idx = 0
  end_idx = 20

Job 2 - Process prompts 20-39:
  start_idx = 20
  end_idx = 40

Job 3 - Process prompts 40-59:
  start_idx = 40
  end_idx = None

The skip mechanism ensures no duplicate generation even with overlapping ranges.


EXAMPLE USAGE:
--------------
1. Generate sample dataset:
   python /home/mtoker/git/simple_skips/create_sample_dataset.py

2. Modify main.py for your job:
   start_idx = 0
   end_idx = 20

3. Submit job:
   submit_job --partition polar4 --nodes 1 --gpu 1 --duration 4.0 \
   --name flux_sample -c "/home/mtoker/git/simple_skips/run_main.sh"
